**Sobre **

Sistema Empresarial com Django para Empresas Médicas Corporativas

**Primeiros requisitos **

**- Identidade visual**

  Simples Utilizando Bootstrap

**- Linguagem do site**

  PT-BR

**- Principal objetivo**

O projeto tem como objetivo desenvolver um sistema empresarial completo para empresas médicas corporativas ou qualquer outro ramo. Utilizando  **Django, Python, HTML, CSS e JavaScript** . Isso inclui a customização do layout do site, um dashboard de configuração, relatórios, um fórum de perguntas e respostas, e foco na segurança e facilidade de uso.

**- Controle de acesso **

  Usuários podem postar suas perguntas/respostas e ter acesso a painel administrativo.

**- Registro de usuários **

  Cadastro livre porem com aprovação do administrador e envio de e-mail.
